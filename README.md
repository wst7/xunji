# 寻迹 · Xunji

**你不需要记住收藏了什么，只需要记住你想找什么。**

把链接丢进来，它替你读完、整理好，存在你自己的手机里。
以后只记得一句模糊的描述，也能从自己的收藏里翻出原文，还会告诉你——是哪里对上了。

[下载 Android 版](https://github.com/wst7/xunji/releases/latest) · [看看它长什么样](https://wst7.github.io/xunji/)

## 它解决什么

收藏夹的问题从来不是「存不进去」，而是「存了以后再也找不到」。
寻迹不要求你分类、打标签、起标题。保存时什么都不用想，找的时候用你记得的那句话。

## 用起来是这样

- **保存不打断你**：粘贴链接，或在微信、浏览器里直接分享过来；剪贴板里有链接时，打开应用会问你要不要保存。
- **内容自己整理**：自动抓取正文、生成摘要和关键词，在后台安静地做完。
- **用记忆找回**：整句中文、关键词、模糊描述都能搜；结果会标出命中的词和匹配原因。
- **完全在本地**：收藏存在手机里，不用登录，不上传，断网也能翻看已经存下的内容。

## 大模型（可选）

不配置也能用——默认的摘要和检索完全离线。
想要更好的摘要，可以在「我的」里填任意 OpenAI 兼容服务（OpenAI、OpenRouter、硅基流动、Ollama、LM Studio 等）。
API Key 只保存在系统钥匙串里，不写日志，也不会离开手机。

## 安装

**Android**：到 [Releases](https://github.com/wst7/xunji/releases/latest) 下载最新的 `xunji-*-arm64.apk`，允许「安装未知来源应用」即可。
安装包用调试密钥签名，适合自己安装，不能上架应用商店。

**iPhone**：暂时没有现成安装包，需要用 Xcode 或 EAS 自行构建。

## 它会遇到的情况

- 微信公众号文章可以正常读取正文。
- 需要登录、验证或付费的页面，只保存链接和能读到的信息。
- 视频只保存标题、简介等公开信息，不做字幕。
- 系统分享在安装包里可用，在 Expo Go 里不行。

## 开发与自托管

产品边界见 [`docs/PRODUCT.md`](docs/PRODUCT.md)，接口、数据库与模块约定见 [`docs/ENGINEERING.md`](docs/ENGINEERING.md)。

```bash
npm install && npm run dev:mobile      # 手机 App（Expo）
docker compose up --build              # 网页版 + API + Worker（自托管）
```

网页版与后端保留用于本地开发和自托管，当前不对外部署；App 不依赖它们。
